stock blobs of ADVAN_6781_S34NF2_V4.0_20250304 (`proprietary-files.txt`,

## Deliberately NOT shipped

- `android.hardware.graphics.allocator-V2-ndk.so` (the UMD DT_NEEDs it; a
  SOFT dependency -- it falls back to HIDL mapper@4.0 with no AIDL
  allocator registered). On lineage-20.0 AIDL's unfrozen `current` IS V2,
  so soong generates four modules of this name and a prebuilt would be a
  duplicate; device.mk requests the platform's `.vendor` variant instead
  (the S666LN's arrangement too). Removed from this repo 2026-09-29.

- `libr54shim.so`: BUILT by the device tree (`device/advan/6781/mali/`,
  `PRODUCT_PACKAGES += libr54shim`), never committed as a binary.
- Stock r32p1 UMDs: `extract-files.sh` installs those (provenance: stock).
  These r54p1 files are committed OVER them; the script already warns when
  an extraction reverts the pair (see its footer).
- `libged` / `libgpu_aux`: STUBBED, not taken (device-tree JOURNAL: taking
  A16's costs libcutils/PQ-stack cascades; A12 stock provides 9/10 + 0/2).
